# Runtime assignment contract

Read the [policy map](../policies/README.md), [plan profiles](../policies/plans.md)
and [execution procedure](../procedures/execute.md), then the assigned phase.
The dispatcher binds role, provider settings, source revision, authority and
allowance in its ledger. A skill or discovery adapter does not replace that run
record or alter the host's default model.

Work only on the named assignment. Writers own exact listed files. Read-only
roles use retained source and separately assigned scratch material for permitted
reproductions. Return complete findings and coverage, including unresolved work.
Retained discovery-link records are inert target text; use their typed manifest
and explicitly retained canonical skills to review them without alias traversal.
Do not edit the implementation checkout as a reviewer, dispatch nested agents,
truncate findings to claim success or treat a failed call as free.

Preserve the exact prompt, original result, checks and input revision. Reconcile
them before resuming an assignment. Unknown effective settings and usage stay
unknown. Report a scope, route, context, authority or budget blocker to the lead;
do not substitute settings or make an extra attempt outside the recorded limits.
