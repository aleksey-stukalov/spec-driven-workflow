# Provenance

This workflow is extracted and adapted from the agentic harness in
[ignatov/gitbob PR 128](https://github.com/ignatov/gitbob/pull/128), at commit
`8a21c9da8e38a55079df81db00200de018375e01`, including the earlier workflow
components used by that revision.

GitBob application rules, importer capabilities, operational data, active work,
and historical execution records remain with GitBob. This repository does not
change or migrate that project.

[OpenSpec](https://github.com/Fission-AI/OpenSpec) is an external dependency.
Its generated skills and commands remain under upstream ownership. The workflow
uses the pinned published package and its supported configuration interfaces.
